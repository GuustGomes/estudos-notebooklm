# 🔍 Troubleshooting ("Cicatrizes")

Durante os testes foram encontradas algumas dificuldades.

## Problema 1

**Respostas muito genéricas.**

### Solução

Adicionar contexto ao prompt.

Exemplo:

> Explique utilizando exemplos reais na área da saúde.

---

## Problema 2

A IA misturava conceitos de IA, Deep Learning e Machine Learning.

### Solução

Especificar claramente o escopo.

Exemplo:

> Responda apenas considerando algoritmos clássicos de Machine Learning.

---

## Problema 3

Respostas extensas.

### Solução

Solicitar:

> Responda em tópicos e utilize no máximo 300 palavras.

---

## Problema 4

Poucos exemplos práticos.

### Solução

Adicionar:

> Inclua um exemplo de aplicação empresarial para cada algoritmo.

# 📘 Miniguia de Estudos

## O que é Machine Learning?

Machine Learning é um ramo da Inteligência Artificial que utiliza algoritmos capazes de aprender padrões presentes nos dados para realizar previsões ou tomar decisões automaticamente.

---

## Tipos de Machine Learning

### Aprendizado Supervisionado

Utiliza dados rotulados.

Exemplos:

* Classificação
* Regressão

Algoritmos:

* Regressão Linear
* Regressão Logística
* SVM
* Random Forest

---

### Aprendizado Não Supervisionado

Utiliza dados sem rótulos.

Objetivos:

* Descobrir padrões
* Agrupar informações

Algoritmos:

* K-Means
* DBSCAN
* PCA

---

### Aprendizado por Reforço

O agente aprende por tentativa e erro através de recompensas.

Aplicações:

* Robótica
* Jogos
* Veículos autônomos
